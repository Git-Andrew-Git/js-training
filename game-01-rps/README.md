# 📚 Game 1: Rock-Paper-Scissors & Number Guessing Arcade

## 🧠 Theory & Concepts

### 1. Game Logic & State Management in JS
Building arcade games involves managing game state (scores, rounds, user choice vs. computer choice), generating random values (`Math.random()`), and updating the UI instantly based on game outcomes.

---

## 🛠️ Requirements & Instructions

Open your `script.js` file in this folder and build an interactive arcade game widget inside `#ui-sandbox`:
1. **Rock-Paper-Scissors**: Buttons for Rock, Paper, and Scissors. The computer picks randomly, and rules determine wins, losses, and ties.
2. **Score Tracker**: Keeps track of player wins, computer wins, and ties across rounds.
3. **Reset Button**: Resets scores and game state.
