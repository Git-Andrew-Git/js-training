# 📚 Project 3: Auth & Service Integration (Google Auth / Firebase Simulator)

## 🧠 Theory & Concepts

### 1. Client-Side Authentication & Protected Routes
Real-world applications require user authentication (Sign Up, Login, Logout) and protected dashboard views. In this project, you will simulate a secure authentication flow with persistent sessions (`localStorage`), role checks, and protected UI views.

---

## 🛠️ Requirements & Instructions

Open your `script.js` file in this folder and build an Auth & Service Integration widget inside `#ui-sandbox`:
1. **Auth Forms**: Login and Sign-Up views with form validation.
2. **Session Persistence**: Stores current user session in `localStorage`.
3. **Protected Dashboard**: When logged in, displays a user dashboard with profile info and a "Logout" button. When logged out, redirects to the login screen.
4. **Mock OAuth Button**: Simulates "Sign in with Google / Third-Party Service".
