# 📚 Project 2: Weather & News Dashboard

## 🧠 Theory & Concepts

### 1. Consuming External REST APIs in Real Apps
A dashboard app pulls live data from third-party APIs (like OpenWeatherMap or public news APIs), handles loading states, displays error handling banners, and renders dynamic UI components based on real-time JSON payloads.

---

## 🛠️ Requirements & Instructions

Open your `script.js` file in this folder and build a dynamic Weather & News Dashboard inside `#ui-sandbox`:
1. **Search Bar**: Allows users to search by city or keyword.
2. **Loading & Error States**: Shows a spinner or loading text while fetching, and friendly error messages if the API fails or a city isn't found.
3. **Dynamic Weather Card**: Displays temperature, condition, humidity, and weather icons.
4. **Recent Searches**: Stores recent search history in `localStorage`.
